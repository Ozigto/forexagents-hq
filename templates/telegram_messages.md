# Telegram Message Templates

## Agent message

```text
{emoji} {agent_name}:
{short_report}
```

## Watch alert

```text
👀 WATCHLIST SETUP

Pair: {pair}
Pattern: {pattern}
Status: {status}
Timing: {timing}

What must happen next:
{next_condition}
```
